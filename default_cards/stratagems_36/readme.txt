三十六计卡组（古朴版） — DragonCard 卡组

内容
- 36 张计策卡：正面计名 + 拼音 + 原文（按语），翻面看 释义 / 典故 / 现代应用。
- 6 张总览卡：每套一张章首卡，介绍该套战略主题，首次浏览看一次。
- 英文版（_en 文件）：零中文，原文/释义/典故 + Reflection（哲思），古朴视觉一致。

字段（中文版 cards.json）
order, set, set_order, name, pinyin, source, explanation, story, modern, type
字段（英文版 cards_en.json）
order, set, set_order, name, pinyin, source, explanation, story, reflection, type

导入方式
1. DragonCard 管理卡组 → 上传模版：选 template.json（中文）或 template_en.json（英文）。
2. 上传数据：选 cards.json（中文）或 cards_en.json（英文）。
3. 无需改库 / 重启。

按钮
翻面 / 朗读（读计名）/ 标记 / 收藏。翻面用 CSS 类切换，不触发额外统计。
