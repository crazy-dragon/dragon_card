三十六计
========

中英双语 42 张：36 计 + 6 张套别总览。正面计名 + 拼音 + 原文，翻面看释义 / 典故 /
现代应用（英版为 Meaning / Story / Reflection）；第 36 计翻面有通关彩蛋。

文件
----
- cards.json  数据（42 张，双语）
- tool.zip    配套小工具「三十六计 · 36 Stratagems」：
              概览 = 6 套 × 6 计方图（点格子就地弹窗看卡）+ 列表视图；
              顶栏切换「中文 / English」；翻面、标记/收藏、朗读、字号滑杆
- meta.json   元信息（作者 / 版本 / 来源 / 许可）
- LICENSE     DragonCard 数据许可 v1.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：翻面、朗读、标记、收藏
