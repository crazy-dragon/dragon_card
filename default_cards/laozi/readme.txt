道德经 · Tao Te Ching
=====================

A free deck: the full text of the Tao Te Ching (81 chapters) plus 5 section
intros — 86 cards. Original text, rare-character readings (ruby), and a few
background notes. **No translation, no paraphrase** — it is a memorisation
tool, not a textbook.

Files
-----
- cards.json  data (86 cards: 81 chapters + 5 section intros)
- tool.zip    companion web tool「道德经」:
              overview = 9x9 chapter grid (tap any cell to peek at the chapter),
              list view = full cards; collapsible notes, TTS, mark / favourite,
              3 skins, font slider
- meta.json   metadata (source / license / counts)

How to use
----------
1. Import cards.json into a deck

3. Study: read, listen, mark, favourite

道德经
======

免费卡组：《道德经》八十一章全文 + 5 张篇首导语，共 86 张。
只给原文、生僻字读音（字上标音）和极少的背景注 ——
**不做白话翻译、不做英译**。它是一套记忆工具，不是教科书。

文件
----
- cards.json  数据（86 张 = 81 章 + 5 张篇首导语）
- tool.zip    配套小工具「道德经」：
              概览 = 9×9 章图（每格一章，点格就地弹窗看原文）+ 列表视图；
              折叠注、朗读、标记/收藏、三套皮肤、字号滑杆
- meta.json   元信息（来源 / 许可 / 计数）
- LICENSE     DragonCard 数据许可 v1.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：读、听、标记、收藏

来源与署名
----------
原文以通行王弼本为底，用维基文库《老子道德經注》（華亭張氏原本）与
ctext.org（中國哲學書電子化計劃）两份独立文本交叉校订，逐章裁定异文。
八十一章的二字章题（体道 / 象元 / 玄德 …）出自托名汉文帝时河上公的
《老子河上公章句》（四部丛刊影宋本），公有领域。注释与注音为原创层。

本卡组免费分发。
