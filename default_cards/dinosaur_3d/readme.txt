Dinosaur 3D Card Deck
==========================

3D dinosaur model cards: resource mode shows a real .glb model;
list/single-card modes show text only.

Data: cards.json (T-Rex, Kid samples)

Place .glb models in static/media/:
- trex.glb
- boy.glb

How to use
----------
1. Put .glb files in static/media/
2. Create a deck, pick the Dinosaur 3D Card template
3. Import cards.json
4. Enter study, tap the cube button (top bar) for resource mode,
   drag to rotate, scroll to zoom the 3D model

------------------------------------------------------------

Dinosaur 3D Card 恐龙 3D 卡片
==============================

3D 恐龙模型卡片：资源模式下展示真实 .glb 模型，列表/单卡模式只显示文字。

数据：cards.json（霸王龙、化骨龙示例）

3D 模型文件需自行放置到 static/media/ 目录：
- trex.glb（霸王龙）
- boy.glb（化骨龙）

使用
----
1. 放置 .glb 模型到 static/media/
2. 新建卡组，选择 Dinosaur 3D Card 模板
3. 导入 cards.json
4. 进入学习 → 点顶栏立方体按钮进入资源模式，拖拽旋转浏览 3D
