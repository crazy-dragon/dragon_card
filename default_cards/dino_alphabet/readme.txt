Dino Alphabet - ABC Deck for Kids
=====================================

26 letters, one dinosaur per letter, candy colors, for young kids (3-6).
The tool reads "A for Ankylosaurus" style (letter + dinosaur name).

Files
-----
- cards.json  data (26 cards, A-Z; each card carries its own color)
- tool.zip    companion web tool「恐龙字母表 · Dino Alphabet」:
              A-Z letter wall (each cell in that dinosaur's own color,
              click to hear "A for …" and jump to the card) + big-letter
              cards (phonics, sample word read-aloud, Chinese name read in
              zh-CN), tap-the-dino bounce animation, mark/favorite, 3 skins
- meta.json   metadata (author / version / license)
- LICENSE     DragonCard Data License v1.0

How to use
----------
1. Import cards.json into a deck
2. In deck detail, upload tool.zip as the deck's mini tool
3. Study: "A for …" read-aloud (en) · 中文名朗读 (zh) · 例词点读 · 标记 · 收藏

恐龙字母表 · 幼儿 ABC 卡组
==============================

26 个字母，每字母配一只恐龙，糖果色，适合 3-6 岁。
工具按「A for Ankylosaurus」朗读（字母 + 恐龙英文名）。

文件
----
- cards.json  数据（26 张，A–Z；每张卡自带恐龙专属颜色）
- tool.zip    配套小工具「恐龙字母表 · Dino Alphabet」：
              A-Z 字母墙（每格是这只恐龙自己的颜色，点格子读「A for …」
              并跳卡）+ 大字母卡片（phonics、例词点读、中文名 zh 朗读）、
              戳恐龙会蹦、标记/收藏、三套皮肤
- meta.json   元信息（作者 / 版本 / 许可）
- LICENSE     DragonCard 数据许可 v1.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：「A for …」朗读（en）· 中文名朗读（zh）· 例词点读 · 标记 · 收藏
