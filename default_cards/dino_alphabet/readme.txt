Dino Alphabet - ABC Deck for Kids
=====================================

26 letters, one dinosaur per letter, candy colors, for young kids (3-6).
Pronunciation reads the LETTER only (not the dino name).

Data: cards.json (26 cards, A-Z)

How to use
----------
1. Create a deck, pick the Dino Alphabet template
2. Import cards.json
3. Tap the speaker to hear the letter; tap the dino to roar

Dino Alphabet 恐龙字母卡组
==============================

26 个字母，每字母配一只恐龙，糖果色系，适合幼儿（3-6 岁）。
发音朗读字母本身（不读恐龙名）。

数据：cards.json（26 张，A-Z）

使用
----
1. 新建卡组，选择 Dino Alphabet 模板
2. 导入 cards.json
3. 点喇叭听字母发音，点恐龙可以"吼叫"互动
