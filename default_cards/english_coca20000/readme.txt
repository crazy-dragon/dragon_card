COCA20000 词卡
==============

COCA top 2000 high-frequency words with phonetic, EN/ZH definitions and
examples. 2000 cards.

Files
-----
- cards.json  data (2000 cards)
- tool.zip    companion web tool「COCA20000 词卡」:
              catalogue pagination, word-card list / single-card, play / peek /
              mark / favorite, emerald & simple style switch
- meta.json   metadata (author / version / source / license)
- LICENSE     DragonCard Data License v1.0

How to use
----------
1. Import cards.json into a deck
2. In deck detail, upload tool.zip as the deck's mini tool
3. Study: pronunciation, mark unknown, favorite, toggle definition
