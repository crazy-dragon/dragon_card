Western Allusions · 西方典故
============================

37 bilingual allusion cards (Greek myth / Roman history / Bible / literary
fairy tales), Chinese-first with an English Corner. 37 cards.

Files
-----
- cards.json  data (37 cards)
- tool.zip    companion web tool「西方典故 · Western Allusions」:
              grouped by theme with section colors, one-line gist + Chinese
              story + modern usage + English Corner + source credit;
              mark / favorite, TTS
- meta.json   metadata (author / version / source / license)
- LICENSE     DragonCard Data License v1.0

How to use
----------
1. Import cards.json into a deck
2. In deck detail, upload tool.zip as the deck's mini tool
3. Study: pronunciation, mark, favorite
