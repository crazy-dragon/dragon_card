# 光点拼词 · 游戏模式记录

> 保留两个游戏化模式。数据同源：`cards.json`；字母统一标准字体（系统 sans-serif 粗体），
> 黑底（#0b0d12）方块、元音暖橙/辅音青紫配色；点字母读字母名（TTS en-US），拼完读整词。

## 模式一：记忆版（V2 · 无序）

核心：**看一眼 → 熄灭 → 凭记忆点**。

- 场上只有单词本身的字母（无干扰），随机撒格、全亮；上方方格拼写槽同步亮出整词
- 演示时长按词长自动算：`1.1s + 0.45s × 词长`（cat 约 2.5s，elephant 约 4.7s），倒计时条走完自动熄灭
- 熄灭后点方块 = **点亮看字母**：是要的字母 → 保留亮起并飞入拼写槽；不是 → 短暂显示 0.6s 后熄灭（翻配对式反馈）
- 点错只计失误，不扣分；「提示」让需要的方块亮 0.8s 后回灭，不计失误
- 「再看一遍」重开本词、重新演示
- 无序 = 字母位置随机，不做顺序演示；玩家按拼写顺序填槽

## 模式二：简版（V6 · 无序常亮）

核心：**常亮直接找**，难度来自大小写 + 少量干扰。

- 5×5 = 25 格（简单档 4×4 = 16 格），格子 81px，字母占格约 2/3（54px）
- 词字母**大写 + 小写各一块**（cat → c C a A t T），**干扰字母 3 个**（简单/中等档固定），其余为不可点空白暗板
- 判定大小写不限（点 `c` 或 `C` 都算）；elephant 双 e 的 4 块任点其一
- 点对 → 该块**灰显锁定**（亮光收走、字母变灰、不可再点），字母飞进拼写槽
- 拼写槽 = 大方格（不用四线三格），上限 74px 按词长自适应；**始终显示小写**（点大写块也落小写）
- 点错只抖红计失误，不扣分；「提示」脉冲需要的字母块；「换个位置」重新随机

### 难度三档（简版）
| 档位 | 网格 | 构成（cat 为例） |
|---|---|---|
| 简单 | 4×4 = 16 | 6 字母块 + 3 干扰 + 7 空板 |
| 中等（默认） | 5×5 = 25 | 6 字母块 + 3 干扰 + 16 空板 |
| 较难 | 5×5 全满 | 6 字母块 + 19 干扰 |

## 实现要点
- 原型文件：记忆版 `_preview/proto_grid.html`（生成器 `gen_proto_grid.py`）、简版 `_preview/proto_grid5.html`（生成器 `gen_proto_grid5.py`）
- 状态机 demo → play → done（记忆版）；简版常亮无演示阶段
- 难度来自**扫描量**而非玩法：干扰控制在 ≤3；难度曲线随词长自适应（长词自动变简单）
- 正式化为模板时：一模板一件事，探针（Playwright）验证交互 + 截图后再落 `template_grid.json`
