I Ching 64 Hexagrams · 易经六十四卦
====================================

Study the 64 hexagrams of the Book of Changes: line diagram, upper/lower
trigram structure, judgment and plain-language meaning.

Files
-----
- cards.json  data (64 hexagram cards)
- tool.zip    companion web tool「周易 · 六十四卦与入门」(one zip, adapts to
              whichever deck it is bound to):
              · this deck  → 卦序方图 (8x8 chart, rows = upper trigram,
                columns = lower trigram, click a cell to jump to the card)
                + hexagram cards with correct top-down line drawing,
                Unicode hexagram glyph, judgment read-aloud
              · 周易入门 deck → 19 intro cards (trigram diagrams drawn
                by the tool)
              mark / favorite · zh-CN TTS · 3 skins
- meta.json   metadata (author / version / license)
- LICENSE     DragonCard Data License v1.0

How to use
----------
1. Import cards.json into a deck
2. In deck detail, upload tool.zip as the deck's mini tool
3. Study: 卦名朗读 (zh) · 卦辞点读 · 标记 · 收藏

易经六十四卦 卡组
==============================

学习《周易》六十四卦：卦画、上下卦结构、卦辞与白话释义。

文件
----
- cards.json  数据（64 张卦卡）
- tool.zip    配套小工具「周易 · 六十四卦与入门」（一个 zip，绑哪个卡组
              就自动切成哪个形态）：
              · 本卡组 → 卦序方图（上卦×下卦 8×8，点格子跳卡）+ 卦卡，
                卦画按正规上下方向绘制、Unicode 卦符、卦辞点读
              · 周易入门卡组 → 19 张入门概念卡（三画卦图由工具绘制）
              标记/收藏 · 中文朗读 · 三套皮肤
- meta.json   元信息（作者 / 版本 / 许可）
- LICENSE     DragonCard 数据许可 v1.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：卦名朗读（zh）· 卦辞点读 · 标记 · 收藏
