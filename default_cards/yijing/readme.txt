I Ching 64 Hexagrams Deck (易经卦象)
=========================================

Study the 64 hexagrams of the Book of Changes: hexagram name,
line diagram, structure, judgment and plain-language meaning.

Data: cards.json

How to use
----------
1. Create a deck, pick the 易经卦象卡 template
2. Import cards.json
3. Read aloud, mark, favorite
