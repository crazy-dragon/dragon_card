I Ching Intro · 周易入门
=========================

Zero-to-basic intro to the Book of Changes: yin/yang, the four images,
the eight trigrams (diagrams drawn by the tool), yao, casting.
Start here before the 64-hexagram deck.

Files
-----
- cards.json  data (19 intro cards)
- tool.zip    companion web tool「周易 · 六十四卦与入门」(one zip, adapts to
              whichever deck it is bound to):
              · this deck → 19 intro cards, trigram diagrams (111/000
                codes in data) drawn by the tool top-down
              · 64-hexagram deck → 卦序方图 + hexagram cards
              mark / favorite · zh-CN TTS · 3 skins
- meta.json   metadata (author / version / license)
- LICENSE     DragonCard Data License v1.0

How to use
----------
1. Import cards.json into a deck
2. In deck detail, upload tool.zip as the deck's mini tool
3. Study: 标题朗读 (zh) · 标记 · 收藏

周易入门 卡组
==============================

易经零基础入门：阴阳、四象、八卦（三画卦图由工具绘制）、爻与起卦。
先学这本，再进六十四卦。

文件
----
- cards.json  数据（19 张入门卡）
- tool.zip    配套小工具「周易 · 六十四卦与入门」（一个 zip，绑哪个卡组
              就自动切成哪个形态）：
              · 本卡组 → 19 张入门概念卡，数据里的三画码（111/000）
                由工具按自上而下绘制成卦图
              · 六十四卦卡组 → 卦序方图 + 卦卡
              标记/收藏 · 中文朗读 · 三套皮肤
- meta.json   元信息（作者 / 版本 / 许可）
- LICENSE     DragonCard 数据许可 v1.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：标题朗读（zh）· 标记 · 收藏
