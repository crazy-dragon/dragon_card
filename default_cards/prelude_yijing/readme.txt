I Ching Intro Deck (周易入门)
================================

Zero-to-basic intro to the Book of Changes: yin/yang, trigrams,
how hexagrams and lines form, how to read, how to divine.
Start here before the 64-hexagram deck.

Data: cards.json

How to use
----------
1. Create a deck, pick the 易经入门卡 template
2. Import cards.json
