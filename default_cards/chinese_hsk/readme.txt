Chinese HSK (Hanzi) - HSK 3.0 Character Deck
=============================================

Data
----
- cards.json  HSK 1-3 (1011 words, free sample)
- tool.zip    companion web tool「HSK 分级词表 · Chinese HSK 3.0」:
              a catalogue + list reader.
              Catalogue: 100 words per page, 112 pages for the full deck.
              Each page number carries a 4px left spine in its HSK level
              colour (HSK 1-6 / 7-9) and a colour for study state (pages
              with unmarked words vs. all-known). Click a page number to
              open it as a tab and read its 100 word cards.
              Search box: type pinyin without tone marks ("ai" matches
              "ài"); each hit jumps to its own page.
              Word cards: hanzi read-aloud (zh), English definition
              read-aloud (en), per-word "Source:" attribution, mark &
              favorite, single-card mode, 3 skins.
              The tool adapts to whichever HSK deck it is bound to
              (this free 1011 sample or a full 11105-word deck).
- meta.json   metadata (author / version / license)
- LICENSE     CC BY-SA 4.0

How to use
----------
1. Import cards.json into a deck
2. In deck detail, upload tool.zip as the deck's mini tool
3. Study: 目录页号找词 → 页内词卡 · 词语朗读 (zh) · 英文释义点读 (en) ·
   去声调搜索 · 标记 · 收藏

License / Attribution
---------------------
HSK 3.0 official character/vocabulary lists (public exam specification);
English definitions: CC-CEDICT (https://cc-cedict.org), CC BY-SA 4.0.
Each card carries its own "Source:" attribution in the tool.

HSK 汉字卡组 · HSK 3.0
==============================

数据
----
- cards.json  HSK 1–3 级（1011 词，免费示例）
- tool.zip    配套小工具「HSK 分级词表 · Chinese HSK 3.0」：
              目录 + 列表式词表。目录按 100 词一页，全量卡组共 112 页；
              页号左侧 4px 色条 = 该页的 HSK 等级（1–6 / 7–9），
              页号底色 = 学习状态（有未掌握 / 全部掌握）。点页号即开页签、
              读该页的 100 张词卡。搜索框不用打声调（搜 "ai" 命中 "ài"），
              命中项一键定位到它所在的页。词卡支持汉字点读 (zh)、
              英文释义点读 (en)、逐词 Source 署名、标记 / 收藏、单卡模式、
              三套皮肤。工具自适应绑定的卡组（本免费 1011 示例或全量 11105 词卡组）。
- meta.json   元信息（作者 / 版本 / 许可）
- LICENSE     CC BY-SA 4.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：目录找页 → 页内词卡 · 词语朗读 (zh) · 英文释义点读 (en) ·
   搜索 · 标记 · 收藏

许可与署名
----------
HSK 3.0 官方词汇表（公开考试大纲）；
英文释义来自 CC-CEDICT（https://cc-cedict.org），CC BY-SA 4.0。
工具内每张词卡带独立的 "Source:" 署名。
