日语五十音图
============

日语基础五十音：46 个清音 + 拨音「ん」，每张含平假名、片假名、罗马字、所属行与例词。
适合零基础入门识记。共 46 张。

文件
----
- cards.json  数据（46 张）
- tool.zip    配套小工具「日语五十音图 · Gojūon」：
              顶栏切换「五十音图 / 卡片」两种视图——5 段 × 11 行真·假名表
              （点格子读假名）与卡片视图（平假名/片假名/罗马字/例词）；
              标记/收藏、日语朗读
- meta.json   元信息（作者 / 版本 / 来源 / 许可）
- LICENSE     DragonCard 数据许可 v1.0

使用
----
1. 导入 cards.json 建卡组
2. 在卡组详情里把 tool.zip 上传为该卡组的小工具
3. 学习：点喇叭听假名发音（日语语音）

使用条款见随附 LICENSE 文件。
