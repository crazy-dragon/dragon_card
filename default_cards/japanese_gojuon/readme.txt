Japanese Gojuon (Hiragana/Katakana) Deck
===============================================

Basic Japanese syllabary: 46 seion + nasal "ん".
Each card shows hiragana, katakana, romaji, its row, and a sample word.
Great for absolute beginners.

Data: cards.json (46 cards)

How to use
----------
1. Create a deck, pick the 日语五十音图 template
2. Import cards.json
3. Tap the speaker to hear the kana (Japanese voice)

日语五十音图 卡组
==============================

日语基础五十音：46 个清音 + 拨音「ん」。
每张卡显示平假名、片假名、罗马字、所属行，附一个例词。
适合零基础入门识记。

数据：cards.json（46 张）

使用
----
1. 新建卡组，选择 日语五十音图 模板
2. 导入 cards.json
3. 点喇叭听假名发音（日语语音）
